Divisibility Rule for 3

Believe it or not! there is a single divisibility rule available to test ALL odd numbers, that Includes all prime numbers except 2 & 5. No more struggles to remember different divisibility rules for different ODD numbers. For any odd number, the divisibility rule is the same. Wow! Is that so simple?... Wait... Please don't get so excited. A small 'if' clause to be introduced in this statement. For any odd number that ends with 1, 3, 7, 9 the divisibility rule is the same. It means this common rule is not applicable for any odd number that ends with 5. Hope this exception does not disappoint us, because we do not want any extra rule for the odd number that ends with 5. We already know a simple rule for that (i.e. the last digit of the dividend must be '5' or '0')

Before go into the rule, let us recall the Stem and Leaf concept. For a given number, 'Leaf' part is the last digit (ones place) of that number and 'Stem' part is the other digits of that number. If the number is 24873, 3 is 'leaf' and 2487 is 'stem'.

Below is the Generalised (or Universal) Divisibility Rule for any Odd number that ends with 1, 3, 7, 9
Let the dividend be 'N' and divisor be 'D'. To check the divisibility of 'D' on 'N', follow these steps.

  • Step1: Break the dividend 'N' into 'Leaf' (L) and 'Stem'(S).
  • Step2: If the last digit of the divisor (D) is not 9, we have to modify the divisor to make its last digit as 9. That means, If the last digit of the divisor is 1, we have to multiply it with 9; If the last digit of the divisor is 3, we have to multiply it with 3; If the last digit of the divisor is 7, we have to multiply it with 7; If the last digit of the divisor is 9, no change is required.
  • Step3: Add '1' to the modified divisor (same divisor if its last digit is already '9') got in 'Step2' and divide the result by 10. Let this final number be R.
  • Step4: Calculate the value C as C = S + (R * L).
    **A very important note:** If (D-R) is a convenient smaller positive number compare to R itself, the formula for finding 'C' is re-written as C = S - (R' * L), where R' = (D-R), but we should stick to ONLY either one formula throughout the process of calculating C value (Re-call the Divisibility Rule for 7, mentioned earlier in this application).
    Repeat this calculation, every time using C as a new dividend 'N' and until C becomes a smaller number to quickly inspect whether it is a multiply of 'D'.
  • Step5: If final C is divisible by 'D', then the original number 'N' is divisible by the divisor 'D'
